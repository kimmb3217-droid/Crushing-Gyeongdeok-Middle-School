# 안동 경덕중학교 뿌시기

Solar Smash에서 영감을 받은 **가상 3D 건물 파괴 샌드박스** 프로토타입입니다. 실제 학교 건물의 정확한 복제품이 아닌, 학교를 연상시키는 단순화된 테스트 모델로 시작합니다.

## 현재 프로토타입
- Unity가 기본 씬을 실행할 때 학교 형태의 블록 건물과 지면을 자동 생성
- 마우스 클릭으로 조준하고 공격
- 공격받은 건물 블록은 피해를 입고, 파괴되면 물리 효과와 함께 떨어짐
- 화면에 파괴율과 조작법 표시
- 외부 에셋이나 패키지 없이 기본 Unity 기능만 사용

## 실행 방법
1. Unity Hub에서 **Unity 2022.3 LTS 이상**의 3D 프로젝트를 새로 만듭니다.
2. 이 저장소의 파일을 프로젝트 폴더에 복사합니다.
3. `Assets/Scripts/PrototypeBootstrap.cs`가 프로젝트 안에 있는지 확인합니다.
4. 빈 씬에 빈 GameObject를 만들고 이름을 `PrototypeBootstrap`으로 지정합니다.
5. `PrototypeBootstrap.cs`를 그 GameObject에 붙입니다.
6. Play를 누릅니다. 카메라, 조명, 학교형 블록 건물, UI는 실행 시 자동 생성됩니다.

## 조작
- 마우스 이동: 조준점 이동
- 마우스 왼쪽 클릭: 공격
- 마우스 휠: 카메라 확대/축소
- R: 씬의 건물 재생성

## 참고
이 프로젝트는 가상의 게임 시뮬레이션입니다. 현실의 학교나 사람에게 위해를 가하기 위한 용도가 아닙니다.
